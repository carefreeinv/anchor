**0.4.2** is a patch on 0.4.1: critic pytest runs in the feature worktree,
`--worktree` is omitted when ensure fails, and `check_plans` reports nested
misfiled plans.

<!-- truncate -->

`anchor review` VERIFICATION pytest and docs-sync use
`infer_finish_git_dir` (`feature/<slug>`), so NVIDIA no longer REVISEs
against unfixed `dev`/`main`. `work.claim` does not pass the operator
checkout as `--worktree` when `ensure_worktree` fails. `check_plans`
reports plan-shaped files nested inside a lane the layout does not treat
as an entry; `Status:` / `Lane:` inside fenced examples no longer fail
the check.

Plan-folders and split-touches branches are not in this tag.
