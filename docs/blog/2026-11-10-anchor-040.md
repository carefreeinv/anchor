**0.4.0** is the first release where `anchor work`, `anchor review`, and
`anchor draft` are the default operator loop, with `anchor release` for the
cut itself.

<!-- truncate -->

Install `anchor` on PATH (`/install-anchor`). From any directory inside a
tree that has `.plans/`, the verbs pick the top ready plan, critic
`review-needed/`, or fill a draft. `anchor release --dry-run` prints
unmerged work and a suggested tag; TTY `--yes` tags; TTY `--push` publishes
without `--force`. The CLI never merges.

Survey and merge still happen on a TTY. Headless `--yes` / `--push` exit 3.
Leftover P2 branches (plan-folders, split-touches) and unpromoted drafts are
not in this tag.
