README, Quick Start, and the skills overview now start with **`anchor work`**,
**`anchor review`**, and **`anchor draft "<desc>"`**. Slash `/work` `/review`
`/draft` remain the in-harness adapters after one successful CLI probe.

`anchor review --promote`. Unreleased CHANGELOG is one Added/Changed/Fixed
stack.
